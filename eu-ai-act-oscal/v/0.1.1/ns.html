Property namespace

https://w3id.org/eu-ai-act-oscal/ns

This namespace identifies the custom properties used by the OSCAL catalog of the EU Artificial Intelligence Act — Regulation (EU) 2024/1689, as amended by Regulation (EU) 2026/1744.

OSCAL lets a catalog attach named properties to controls and groups. Properties that are not part of the OSCAL core vocabulary must declare which vocabulary they belong to, via an ns value. Every property this catalog defines carries the URI above, so a consumer can tell our vocabulary apart from NIST's and from anyone else's.

This URI is an identifier, not a schema endpoint. It names the vocabulary; it does not return a machine-readable schema document. Nothing should be fetched from it at validation time.

How it appears

Always inside an OSCAL props array:

{
  "name":  "application-date",
  "value": "2027-12-02",
  "ns":    "https://w3id.org/eu-ai-act-oscal/ns"
}

When an obligation starts applying

The Act applies in stages, and the 2026 amendment moved several of those dates. The catalog keeps both the current date and the one it replaced, so a reader can see that a date moved rather than having to know it did.

NameMeaningExample values
application-dateDate the obligation applies from, as currently in force.2025-02-02, 2025-08-02, 2026-08-02, 2027-12-02
application-date-originalThe date before the amendment moved it.2026-08-02
application-date-annex-iSeparate date for Annex I high-risk systems.2028-08-02
application-date-annex-i-originalIts pre-amendment counterpart.2027-08-02
application-date-statusFlags a date the Regulation does not settle. Present only where genuinely unresolved.unresolved-see-docs-amendments
obligation-windowDate from which the duty must actually be met.2025-02-02, 2027-12-02
obligation-window-originalIts pre-amendment counterpart.2026-08-02
later-obligation-windowA second, later deadline where one control carries two.2026-12-02
marking-transition-windowTransition deadline for marking duties.2026-12-02
Three articles — 72, 73 and 86 — carry application-date-status: unresolved-see-docs-amendments. That is deliberate: the amended text does not settle them, and the catalog records the open question instead of inventing an answer. The reasoning is in docs/AMENDMENTS.md.

Stability

The namespace URI is permanent. Property names follow the catalog's versioning: within a major version, names are added but not repurposed. A name that changes meaning gets a new name.
