Permanent identifiers

This site is the resolution target for four w3id.org namespaces. It exists so those identifiers keep working — permanently, and independently of where the underlying projects live.

Why a separate site

A w3id.org identifier is a promise that a name will outlive its hosting. The promise is kept by a redirect: w3id.org/… points here, and this site serves the vocabulary or document. Keeping that target separate from the project repositories means a project can move, be renamed, or change hosts without breaking a single published identifier — only the redirect changes.

This is a showcase, not a source. Every file under the four directories below is generated from the corresponding project repository; nothing here is authored by hand. The canonical copy of each artifact lives with its project.

The four namespaces

  • EU AI Act — OSCAL catalog

    A machine-readable NIST OSCAL rendering of the obligations of Regulation (EU) 2024/1689, as amended by Regulation (EU) 2026/1744.

    Properties https://w3id.org/eu-ai-act-oscal/ns
    Catalog https://w3id.org/eu-ai-act-oscal/catalog
    Profiles https://w3id.org/eu-ai-act-oscal/profiles/{id}
    Licence Apache-2.0

  • ATO — Agentic Tools Observatory

    A FAIR / Linked-Open-Data registry and observability vocabulary for agentic-AI tools.

    Ontology https://w3id.org/ato/ns#
    Instances https://w3id.org/ato/id/{type}/{id}
    Taxonomy https://w3id.org/ato/scheme#
    Licence code Apache-2.0 · vocabulary CC-BY-4.0

  • CAES — claims with provenance

    An open vocabulary for assertions that carry their own source, evidence, confidence and supersession history. Resolution is optional, cacheable and offline-viable by design — never a mandatory runtime dependency.

    Ontology https://w3id.org/caes/ns#
    Versioned https://w3id.org/caes/v1/{term}
    Durable form urn:caes:v1:type:{term}

  • PAP — the Parallel Agent Protocol

    An open protocol for coordinating multiple autonomous agents over shared state: claims, ownership, liveness and handover.

    Ontology https://w3id.org/pap-protocol/ns#
    Versioned https://w3id.org/pap-protocol/v1/{term}
    Licence spec CC-BY-4.0 · implementation Apache-2.0

Content negotiation

The RDF vocabularies (ATO, CAES, PAP) answer an Accept header with an HTTP 303 See Other to the matching serialisation — Turtle, RDF/XML, JSON-LD, N-Triples, or HTML documentation. A browser gets the documentation; a tool gets the data. The OSCAL catalog is JSON and is served directly.
